# Agent Relay Dashboard

The Agent Relay dashboard gives a self-hosted team a shared view of sessions, workflows and workspace settings through its existing sign-in.

## Get started

See the [repository guide](docs/repository-guide.md) for the supported setup, current limitations and technical reference.

## Design the dashboard

Run `npm ci` and `npm run design` for the local designer workbench: the real dashboard, linked synthetic scenarios and a browsable data catalog, with no backend setup. Start with the [designer onboarding guide](docs/designer-onboarding.md).
